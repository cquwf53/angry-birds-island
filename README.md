# 愤怒的小鸟 · 怒鸟群岛

[直接游玩](https://cquwf53.github.io/angry-birds-island/)

World Tour 3.0：经典卡通风格的非官方同人复刻与玩法扩展。

- 12 个世界、120 个主线关卡、360 颗星、120 枚隐藏金蛋。
- 10 种小鸟，加入寒冰脆化、泡泡升空和巨型膨胀。
- 7 种建筑材质，传送门、引力场、传送带、气流与弹簧。
- 无限远征：输入种子、三档难度、生命次数与沿途升级。
- 12 道大师试炼、奖励目标、每日挑战、图鉴与成就。
- 原24关和存档保留，支持本地保存和手机触屏。

拖动弹弓上的小鸟，松手发射。飞行时点击场景或按空格发动技能。R 重试，P 暂停，M 声音，C 慢动作，F 全屏。手机横屏游玩更舒适。

游戏是完全自包含的单个 HTML，下载 index.html 后也可离线游玩。角色、场景和音效由 Canvas / WebAudio 在浏览器中生成。

本仓库保存已验证的发布文件。物理引擎为 Matter.js 0.20.0，MIT 许可见 LICENSE-Matter.txt。
